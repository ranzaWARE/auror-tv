Link TMDB

Search tells where a film or series is to watch in Italy, and TMDB is where it asks. It needs a free API key; the key stays on the TV only.

  1. Sign up or sign in at themoviedb.org.
  2. Settings, API: ask for a key for personal use.
  3. Copy the API key (32 letters and digits), not the read access token.

This product uses the TMDB API but is not endorsed or certified by TMDB. Where titles are to watch comes from JustWatch.
